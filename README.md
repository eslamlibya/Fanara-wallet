# Fanara Wallet (نسخة تجريبية)

نموذج تجريبي لتطبيق محفظة رقمية (PWA) بعربية RTL. **كل البيانات وهمية** ولا يوجد أي اتصال بمصرف أو خادم.
الشعارات والأسماء المعروضة في «متجر الكروت» تعود لأصحابها وتظهر للعرض التجريبي فقط.

- حساب الدخول التجريبي: `0912345678` / `demo`
- التشغيل المحلي: `python3 -m http.server 8080` ثم http://localhost:8080
- الاختبارات: `node tests.js index.html`
- التقرير: `REPORT.md`
